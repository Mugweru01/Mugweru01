# 👋 About Me

I'm **Edwin Wachira**, a Software Engineer, Data Engineer, Data Analyst and Founder based in Kenya.

I'm passionate about building products that solve meaningful problems through thoughtful engineering, intelligent data systems and exceptional user experiences.

My work spans modern web engineering, cloud infrastructure, analytics, artificial intelligence and scalable backend systems.

Rather than simply writing code, I enjoy architecting complete systems—from database design and APIs to analytics pipelines and cloud deployments.

I'm currently focused on engineering software that scales, creating reliable data platforms and building products that make everyday processes dramatically simpler.
